# AutoCenterPDV

Canal de distribuição do **AutoCenterPDV**, sistema local de Ordem de Serviço para oficina
mecânica / auto center (veículos, serviços, ordens de serviço, técnicos, orçamentos, garantia,
agendamentos, contratos e chamados técnicos).

Este repositório serve para distribuir os **instaladores oficiais do sistema (Windows)**. O
aplicativo instalado se atualiza sozinho a partir daqui (electron-updater).

O código-fonte do aplicativo não é distribuído por aqui.
